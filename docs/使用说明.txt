ACE COMBAT 8 · 简体汉化管理器    v1.3

【这是什么】
把本目录 payload\ 里的文件装进游戏目录，让游戏显示简体中文。
仅供离线单人游玩使用。

【怎么用】
1. 双击 AC8汉化管理器.exe
2. 确认「游戏目录」正确（不对就点「浏览…」选到 ...\steamapps\common\ACE COMBAT 8）
3. 点「启用汉化」
4. 点「启动游戏」

【首次使用】
第一次点「启用汉化」会弹一个须知（免责声明 + 多人模式封号警告），
必须停留 3 秒才能确认。点过一次就不再弹。

【检查更新】
点【检查更新】可以把译文包与代理 DLL 更新到最新版；
管理器启动时也会自动查一次，只有发现新版才提示。
下载后会校验大小与 sha256，全部通过才替换；中途失败不会动现有文件。

【停用】
点「停用汉化」即可移除汉化文件，官方文件不会被改动。
被覆盖掉的旧文件会备份到本目录下的 _backup\。

【界面上那几行是什么意思】
  游戏目录   找到的游戏根目录
  汉化包     译文包是否已安装、多大、以及它是什么时候构建的
  代理 DLL   让未签名的译文包能被游戏加载的那个模块
  资源版本   当前 payload 里的译文包是哪个版本
  游戏版本   游戏是否仍是这个汉化适配的版本（游戏更新过会显示「未适配」）
  上次运行   上一次游戏启动时汉化有没有成功加载

【命令行】
  AC8汉化管理器.exe status     打印状态（就绪时退出码 0）
  AC8汉化管理器.exe enable     启用汉化
  AC8汉化管理器.exe disable    停用汉化（恢复原版）
  AC8汉化管理器.exe launch     启动游戏
  AC8汉化管理器.exe check      只检查有没有新版（0=已最新，3=有新版）
  AC8汉化管理器.exe update     检查并下载更新
  AC8汉化管理器.exe help       显示帮助

【注意】
- 仅限离线单人。请勿用于多人模式。
- 游戏更新后「游戏版本」可能显示「未适配」，那需要新版代理 DLL。
- 运行日志：游戏目录\Game\Binaries\Win64\AC8CNDinput.log
